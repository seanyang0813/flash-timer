# Classification proof extract: infinite Matsumoto power twists

This deployed note is a compact source-locked extract for the `/proof` inspector. It is **not** a replacement for the complete research repository or its deterministic checker.

## Setup

Work in the closed genus-two mapping class group. Products act on curves rightmost first. Put

```text
F   = (B0 B1 B2 c)^2
H   = <B0,B1,B2,c>
d   = (t4 t3)^6 = t_delta
W_n = F F^(d^n)
K_n = <H,d^n H d^-n>.
```

The equivalence relation is generated by elementary Hurwitz moves and arbitrary simultaneous global conjugation.

Hurwitz moves preserve the subgroup generated by all factors; simultaneous global conjugation conjugates that subgroup. Therefore

```text
W_m ~_(H,conj) W_n  =>  K_m and K_n are conjugate.
```

## Genus-two Torelli detector

Let `I_2` be the genus-two Torelli group and `S` the set of integral symplectic splittings of `H_1(Sigma_2;Z)`. Mess's theorem gives a canonical equivariant abelianization

```text
mu : I_2 -> Z[S]
mu(t_gamma) = e_(s_gamma)
mu(g x g^-1) = rho(g) mu(x)
```

for positive separating twists. This is used instead of the ordinary Johnson target, which vanishes in genus two because

```text
rank(Lambda^3 H / H) = 4 - 4 = 0.
```

The source-locked quotient-torus calculation and Kurosh subgroup theorem give

```text
H intersect I_2 = normal_closure_H(c)
mu(H intersect I_2) = Z[O_c].
```

For `h in H`, set

```text
a_h(n) = d^n h d^-n h^-1.
```

Equivariance gives

```text
mu(a_h(n)) = n(e_(s_d) - e_(rho(h)s_d)).
```

If `I(O_d)` is the augmentation-zero lattice in `Z[O_d]`, the intrinsic formula is

```text
mu(K_n intersect I_2) = Z[O_c] direct-sum n I(O_d).    (15.1)
```

## Orbit separation

The common homology image is `R=rho(H)`. Every symplectic normalizer of `R` preserves the invariant plane `L` and `L mod 2`. The two source splittings have distinct unordered profiles:

```text
theta(s_c) = {0,0}
theta(s_d) = {1,1}.
```

Hence no normalizer exchanges `O_c` and `O_d`. An exact Pluecker calculation shows that `I(O_d)` is nonzero and contains a primitive difference. Conjugacy of `K_m` and `K_n` therefore forces

```text
|m| I(O_d) = |n| I(O_d),
```

and hence `|m|=|n|`.

## Sign symmetry and converse

Global conjugation by `d^-n` sends

```text
F F^(d^n)  ->  F^(d^-n) F.
```

The two blocks have equal product, so the pure equal-product block shuttle exchanges them and gives `F F^(d^-n)=W_-n`. Thus

```text
W_n ~_(H,conj) W_-n.
```

Combining necessity and sign symmetry:

```text
W_m ~_(H,conj) W_n  iff  |m|=|n|.                     (15.2)
```
